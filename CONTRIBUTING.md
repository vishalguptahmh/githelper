# Contributing

Thanks for considering a contribution to Git Helper! This project is a community-friendly
cheat sheet of useful Git commands and workflows, so contributions are welcome and easy to make.

## How to contribute

1. Fork the repository and create a new branch for your change.
2. Add or update a section in [`README.md`](README.md):
   - Keep the existing style: a `###` heading, a one-line description, and a fenced code block
     with the command(s).
   - Use generic, non-machine-specific examples (e.g. `REMOTE_URL`, `branch_name`, `<filename>`)
     instead of personal file paths or usernames.
   - Add a link to your new section in the **Contents** list at the top of the README.
3. Double check that the anchor link in the Contents list matches the heading. GitHub generates
   anchors by lowercasing the heading and replacing spaces with hyphens, e.g.
   `### Stash Changes` becomes `#stash-changes`.
4. Open a pull request with a short description of what you added or fixed.

## Reporting issues

If you find an incorrect command, a broken link, or a typo, please
[open an issue](../../issues/new) describing the problem, or submit a pull request with the fix.

## Code of conduct

Be respectful and constructive. This is a small, friendly reference project meant to help
developers of all experience levels.
